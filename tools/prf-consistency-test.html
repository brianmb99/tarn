WebAuthn PRF consistency test

Verifies the assumption that an OS-synced passkey produces the same PRF output on every device that shares the credential (iCloud Keychain across Apple devices, Google Password Manager across Android/Chrome devices, etc.).

Page must be served over HTTPS or localhost. Uses a fixed salt so PRF outputs are directly comparable across devices and runs.

How to use

  1. On Device A (e.g. Mac), click Register passkey. Approve the platform-authenticator prompt (Touch ID / Face ID / Windows Hello).
  2. Wait a minute for OS sync to propagate the passkey to your other devices on the same account.
  3. On Device A, click Authenticate (PRF). Note the printed credential ID and PRF hex.
  4. On Device B (e.g. iPhone, same Apple ID), open this page and click Authenticate (PRF) — the synced passkey should be offered. Pick it. Note the credential ID and PRF hex.
  5. Compare:
    • Same credential ID + same PRF hex = assumption holds. Multi-device passkey continuity works.
    • Same credential ID + different PRF hex = assumption fails. Synced credential, but PRF outputs differ across devices.
    • Different credential IDs = the synced credential wasn't found, you authenticated with a different one. Try again, picking the synced passkey explicitly.

Repeat for each device pair under test (Mac↔iPhone, Windows↔Android, etc.).
